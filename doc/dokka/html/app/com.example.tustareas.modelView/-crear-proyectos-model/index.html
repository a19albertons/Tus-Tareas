fun guardarProyecto(nombre: String, descripcion: String)

Guarda o modifica un proyecto en función del id del dto del proyecto, si el id es 0 se guarda un nuevo proyecto sino se modifica el existente. Comprueba logicas de negocio, actualzia campos recibidos y lanza mensajes error en caso de error o fallo en las validaciones. Si todo es correcto se eactualiza corectamente.
